Modo música

Las luces siguen el sonido del Mac: cada columna de teclas es una banda, con los graves a la izquierda. La primera vez, macOS pide permiso para «grabar el audio del sistema». Mientras está en marcha no se pueden cambiar otras cosas del teclado.

Pinta las teclas

Elige un color y pincha las teclas (o arrastra por encima). Las rayadas están apagadas.

Keyboard behavior

Volver a empezar

«Volver a mandar» envía al teclado lo que este Mac tiene guardado (teclas, luces o colores y ajustes): sirve si el teclado se ha reseteado o lo has usado en otro ordenador. Use the keyboard’s factory shortcut if you need a full reset.
